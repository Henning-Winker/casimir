casimir: concept and layers

A catch-survey simulator in which the true catch is known. A simulated island fishery is sampled with a multi-stage landing-site survey, raised to catch per species and fleet segment, and judged against the truth over many repeats.

{{LANDING_SVG}}

Island X and the multi-stage design follow the FAO training concept by Pedro Barros (Data Collection and Estimation of Fisheries Quantities). Package by Henning Winker and Pedro Barros.

Seven layers, each a plain R function returning one object

The app only collects inputs and calls these functions, so everything done in the app can be repeated in a script. Pick a layer to see what goes in, what comes out, and what it looks like on Island X.

Each stage samples a little of the one above, and raising multiplies back up

Hover or tap a stage to see the estimator step that raises it.

    The whole survey in eight lines of R

    island_x()→cas_fishery→cas_frame→cas_design→cas_sample→cas_estimate→cas_eval
    library(casimir)
fish <- cas_fishery(island_x(), seed = 1)          # the island and its true landings
d    <- cas_design(m = 6, n = 3, w_kg = 10)         # 6 site-days per site type and quarter
s    <- draw_sample(fish, d, seed = 2)              # field forms A, B, C
e    <- estimate_catch(s)                           # catch per species with intervals
catch_by(e, by = "segment", fishery = fish)         # by fleet segment, against the truth
ev   <- replicate_design(fish, d, R = 1000)         # bias, CV and coverage over repeats
sv   <- run_survey(fish, d)                         # a five-year programme
run_app()                                           # the same steps in the Shiny app
